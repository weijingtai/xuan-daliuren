# 大六壬多流派重构技术方案

## 背景

当前 xuan-daliuren 项目仅支持"御定大六壬"这一流派，代码中存在大量硬编码耦合。本方案旨在抽象出通用接口，使后续添加新流派变得简单。

## 一、当前代码耦合点分析

### 1. 直接耦合"御定"的代码位置
- `lib/domain/entities/yuding_entry.dart` - 御定专用实体类
- `lib/domain/services/yuding_keti_match_service.dart` - 御定匹配服务
- `lib/data/repositories/da_liu_ren_repository_impl.dart` - 硬编码御定路径
- `lib/presentation/widgets/yu_ding_display_widget.dart` - 御定专用UI组件

### 2. 数据资产
- `assets/da_liu_ren/御定大六壬.json` - 御定专用数据

## 二、抽象接口设计

### 1. 流派接口 (DaLiuRenSchool)

```dart
/// 大六壬流派抽象接口
abstract class DaLiuRenSchool {
  /// 流派唯一标识符 (如: "yuding", "bifa", "kejing")
  String get id;
  
  /// 流派显示名称 (如: "御定大六壬", "毕法赋")
  String get displayName;
  
  /// 流派描述
  String get description;
  
  /// 流派代表书籍
  String get representativeBook;
  
  /// 流派特点标签
  List<String> get tags;
  
  /// 加载流派数据
  Future<void> loadData();
  
  /// 数据是否已加载
  bool get isLoaded;
  
  /// 根据日干支和局名匹配课体
  Future<List<SchoolEntry>> matchEntries(String dayJiaZi, String juName);
  
  /// 获取所有条目数量
  Future<int> get entryCount;
}
```

### 2. 统一条目基类 (SchoolEntry)

```dart
/// 流派条目基类
abstract class SchoolEntry {
  /// 条目标题 (如: "甲子日第一局干上子")
  String get title;
  
  /// 日干支 (如: "甲子")
  String get dayJiaZi;
  
  /// 局名/地支 (如: "寅")
  String get juName;
  
  /// 局数
  int get juNumber;
  
  /// 课体名称列表 (如: ["伏吟", "元胎"])
  List<String> get keTiNames;
  
  /// 课义
  String get meaning;
  
  /// 解释
  String get explanation;
  
  /// 断语
  String get prediction;
  
  /// 杂占 (类别 -> 解释)
  Map<String, String> get details;
  
  /// 经典引用 (书名 -> 内容)
  Map<String, String> get bookReferences;
  
  /// 所属流派ID
  String get schoolId;
}
```

### 2. 流派注册表

```dart
/// 流派注册表
class SchoolRegistry {
  static final Map<String, DaLiuRenSchool> _schools = {};
  static String _defaultSchoolId = 'yuding';
  
  /// 注册流派
  static void register(DaLiuRenSchool school) {
    _schools[school.id] = school;
  }
  
  /// 获取流派
  static DaLiuRenSchool? get(String id) => _schools[id];
  
  /// 获取所有流派
  static List<DaLiuRenSchool> get all => _schools.values.toList();
  
  /// 获取默认流派
  static DaLiuRenSchool get defaultSchool => _schools[_defaultSchoolId]!;
  
  /// 设置默认流派
  static void setDefault(String id) {
    if (_schools.containsKey(id)) {
      _defaultSchoolId = id;
    }
  }
}
```

## 五、新增流派的步骤

当需要添加新流派时，只需：

1. **准备数据**：将流派数据整理成统一JSON格式
2. **创建实现**：新建 `xxx_school.dart` 实现 `DaLiuRenSchool`
3. **注册流派**：在初始化时调用 `SchoolRegistry.register(XxxSchool())`
4. **添加资源**：将数据文件放入 `assets/da_liu_ren/schools/xxx/`

无需修改现有代码，完全符合开闭原则。

## 八、注意事项

1. **向后兼容**：重构过程中保持现有功能不变
2. **渐进式**：可以一个流派一个流派地添加
3. **数据质量**：确保数据来源可靠，必要时人工校对
4. **性能考虑**：流派数据量大时考虑懒加载

---

## 九、总结

本方案通过抽象接口和注册机制，将大六壬的流派支持从硬编码改为可扩展架构。核心思想是：

1. **接口抽象**：定义统一的流派和条目接口
2. **注册机制**：通过注册表管理所有流派
3. **开闭原则**：对扩展开放，对修改关闭
4. **渐进实施**：可以逐步添加新流派

这样既保持了现有御定六壬功能的稳定性，又为后续扩展打下了良好基础。
