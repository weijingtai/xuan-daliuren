# 毕法赋数据格式说明

## 数据来源
《毕法赋》是宋代凌福之编撰的大六壬经典，以歌诀形式总结占断要诀，共100条法则。

## 数据结构

```json
{
  "school_id": "bifa",
  "school_name": "毕法赋",
  "description": "宋代大六壬经典，以歌诀形式总结100条占断法则",
  "entries": [
    {
      "id": 1,
      "title": "前后引从升迁吉",
      "category": "三传",
      "content": "三传引从天干者，如初传在干前，末传在干后...",
      "explanation": "引从格主升迁、进益、吉庆之事...",
      "examples": [
        {
          "dayJiaZi": "甲子",
          "situation": "初传寅，末传亥...",
          "interpretation": "此为引从格，主升迁..."
        }
      ],
      "related_rules": [2, 3, 5],
      "tags": ["三传", "升迁", "吉"]
    }
  ]
}
```

## 字段说明

### 顶层字段
- `school_id`: 流派唯一标识
- `school_name`: 流派显示名称
- `description`: 流派描述
- `entries`: 条目列表

### 条目字段
- `id`: 条目序号（1-100）
- `title`: 法则标题（歌诀首句）
- `category`: 分类（如"三传"、"四课"、"天将"等）
- `content`: 法则原文（歌诀全文）
- `explanation`: 法则解释
- `examples`: 应用示例列表
- `related_rules`: 相关法则编号
- `tags`: 标签列表

### 示例字段
- `dayJiaZi`: 示例日干支
- `situation`: 具体情况描述
- `interpretation`: 解读

## 实现建议

由于毕法赋的结构与御定六壬不同（御定以日干支+局为索引，毕法赋以法则为索引），建议：

1. 创建 `BifaSchool` 实现 `DaLiuRenSchool` 接口
2. 实现不同的匹配逻辑：
   - `matchEntries(dayJiaZi, juName)` 可能返回空（因为毕法赋不按日干支索引）
   - 新增 `matchByCategory(String category)` 按分类匹配
   - 新增 `getRuleById(int id)` 按编号获取法则
3. UI层需要适配不同的显示方式

## 100法则分类

1. **三传类**（约30条）：引从、拱夹、间传、连茹等
2. **四课类**（约20条）：克贼、比用、涉害等
3. **天将类**（约25条）：贵人、腾蛇、朱雀等
4. **神煞类**（约15条）：德、合、禄、马等
5. **其他类**（约10条）：空亡、刑冲、破害等

## 数据收集优先级

建议按以下顺序收集整理：

1. **三传类**：最常用，优先级最高
2. **四课类**：基础重要
3. **天将类**：进阶内容
4. **神煞类**：补充内容
5. **其他类**：特殊情况
