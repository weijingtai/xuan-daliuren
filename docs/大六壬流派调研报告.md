# 大六壬流派调研报告

## 调研日期
2026-05-23

## 一、大六壬主要流派概览

大六壬是中国古代三式（太乙、奇门、六壬）之一，历史悠久，流派众多。以下是主要流派：

### 1. 御定六壬派（皇家派）
- **代表书籍**：《御定大六壬直指》（清康熙年间宫廷编撰）
- **特点**：
  - 皇家官方版本，体系最为完整规范
  - 以720课为基础，涵盖60日干支 × 12时辰
  - 包含：课体、课义、解释、断语、杂占、经典引用
  - 目前程序中已实现此派

### 2. 毕法赋派（经典派）
- **代表书籍**：《毕法赋》（宋代凌福之）
- **特点**：
  - 以歌诀形式总结占断要诀
  - 共100条法则，朗朗上口便于记忆
  - 强调"类神"取用和"三传"变化
  - 是大六壬学习的基础必读

### 3. 课经派（课体派）
- **代表书籍**：《大六壬课经》（明代陈公献）
- **特点**：
  - 以课体分类为核心
  - 将64种课体（八专、伏吟、返吟等）作为占断基础
  - 强调"课格"决定吉凶走向

### 4. 指南派（实践派）
- **代表书籍**：《大六壬指南》（明代陈公献）
- **特点**：
  - 注重实际占验案例
  - 收录大量古今占例
  - 强调"活法"而非死板套用

### 5. 管辂神书派（古法派）
- **代表书籍**：《管辂神书》（传为三国管辂所著）
- **特点**：
  - 保留较古老的占法体系
  - 重视"天将"与"神煞"的作用
  - 占法较为简略直接

### 6. 大六壬大全派（集成派）
- **代表书籍**：《大六壬大全》（明代郭御青）
- **特点**：
  - 集大成之作，收录诸家之说
  - 内容最为丰富全面
  - 包含基础理论、课体、神煞、占法等

### 7. 六壬粹言派（精要派）
- **代表书籍**：《六壬粹言》（清代刘赤江）
- **特点**：
  - 精选诸家精华
  - 注重实用性和可操作性
  - 适合进阶学习

### 8. 壬归派（归类派）
- **代表书籍**：《壬归》（清代）
- **特点**：
  - 按占事类型分类（婚姻、疾病、出行等）
  - 便于查阅具体事项的占法
  - 实用性强

## 二、各流派核心差异对比

| 维度 | 御定六壬 | 毕法赋 | 课经派 | 指南派 |
|------|----------|--------|--------|--------|
| **理论基础** | 官方规范 | 歌诀法则 | 课体分类 | 案例实证 |
| **课体数量** | 720课 | 100法则 | 64课格 | 不限 |
| **占断重点** | 综合分析 | 类神取用 | 课格定性 | 活法变通 |
| **神煞使用** | 中等 | 较少 | 中等 | 灵活 |
| **适用场景** | 通用 | 快速占断 | 结构分析 | 复杂问题 |
| **学习难度** | 中等 | 较易 | 中等 | 较难 |

## 三、公共元素分析（可抽象部分）

### 1. 基础数据层（所有流派共享）
- **天干地支系统**：10天干、12地支、60甲子
- **四课三传**：四课（干上、支上、干阴、支阴）、三传（初传、中传、末传）
- **天将系统**：12天将（贵人、腾蛇、朱雀等）
- **神煞系统**：各类神煞的起法

### 2. 计算引擎层（可复用）
- **排盘算法**：根据日干支、时辰排出四课三传
- **寄宫计算**：天干寄宫规则
- **月将计算**：月将起法
- **节气判断**：用于确定月将交接

### 3. 展示层（可统一）
- **课盘显示**：天盘、地盘、四课、三传的可视化
- **神煞显示**：神煞在盘中的位置
- **天将显示**：天将在盘中的排列

### 现有结构
```
lib/

│   ├── entities/

└── assets/
    └── da_liu_ren/
        └── 御定大六壬.json                  # 御定数据
```

### 问题分析
1. **流派耦合**：代码中直接引用"御定"相关类名和路径
2. **扩展困难**：添加新流派需要修改多个文件
3. **数据路径硬编码**：资源路径在代码中写死

## 五、重构建议

### 1. 抽象流派接口
```dart
// 流派接口
abstract class DaLiuRenSchool {
  String get name;           // 流派名称
  String get displayName;    // 显示名称
  String get description;    // 描述
  
  // 加载该流派的数据
  Future<void> loadData();
  
  // 匹配课体
  Future<List<String>> matchKeTi(DaLiuRenPanModel pan);
  
  // 获取解释内容
  Future<SchoolEntry?> getEntry(String dayJiaZi, String juName);
}
```

### 2. 统一数据模型
```dart
// 统一的流派条目基类
abstract class SchoolEntry {
  String get title;
  List<String> get body;           // 原文/主要内容
  String get meaning;              // 课义
  String get explanation;          // 解释
  String get prediction;           // 断语
  Map<String, String> get details; // 杂占
  Map<String, String> get books;   // 经典引用
}
```

### 3. 流派注册机制
```dart
class SchoolRegistry {
  static final Map<String, DaLiuRenSchool> _schools = {};
  
  static void register(DaLiuRenSchool school) {
    _schools[school.name] = school;
  }
  
  static DaLiuRenSchool? get(String name) => _schools[name];
  
  static List<DaLiuRenSchool> get all => _schools.values.toList();
}
```

### 4. 资源目录结构调整

## 七、总结

大六壬流派众多，各有特色。当前程序仅实现了"御定六壬"这一官方流派。建议：

1. **保持御定为核心**：作为最规范的版本，适合作为默认流派
2. **抽象公共部分**：将排盘、天将、神煞等公共元素抽离
3. **渐进式扩展**：按优先级逐步添加其他流派
4. **统一数据格式**：所有流派数据采用统一的JSON结构

这样既保持了现有功能的稳定性，又为未来扩展打下了良好基础。
