     Daliuren Feature Recovery Plan

     Context

     问题: xuan-daliuren 独立仓库缺少 xuan monorepo 中 daliuren 的许多功能。

     关键发现: xuan monorepo 当前的 daliuren/ 子模块指向的就是 xuan-daliuren.git
      同一仓库，文件完全一致。缺失的功能存在于 monorepo 的 git 历史中 — 在将
     daliuren 从内联目录转为 submodule 时（commit 10bfe5e
     附近），旧架构的代码被删除了。这些功能需要从 xuan monorepo 的 git
     历史中恢复。

     当前 standalone 架构: MVVM + Clean Architecture（新版策略模式 calculators）
     旧 monorepo 架构: 单体 service 类 + Drift 数据库 + Protobuf

     ---
     Phase 1: 准备工作

     1. 克隆 xuan.git 到临时目录（需要完整历史以访问旧提交）
     git clone https://github.com/weijingtai/xuan.git /tmp/xuan-recovery-temp

     2. 从 git 历史中提取旧版 daliuren 代码到对比目录
     git -C /tmp/xuan-recovery-temp archive <pre-migration-commit>:daliuren/ |
     tar -x -C /tmp/xuan-old-daliuren/

     3. 同时提取 monorepo 级别的资产文件（shen_sha、da_liu_ren proto 等）

     ---
     Phase 2: 逐层对比与决策

     对比格式说明

     - 仅旧版有: 需要决定是否迁移
     - 仅新版有: standalone 新开发的，保留
     - 两版都有但不同: 需要逐文件比较决定
